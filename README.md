# 刷题系统 — 需求规格说明书

> 版本：v1.0 | 日期：2026-07-04

---

## 一、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 数据库 | MySQL 8.0 | 维护 `initial.sql`（建表）和 `seed_data.sql`（初始数据） |
| 后端 | SpringBoot 4.1.0 | controller / mapper(@Select) / models / service+impl / dto / common / config / utils |
| 前端 | Vue 3 | Vant 4 组件库 + Vue Router + Pinia 状态管理 + Axios |
| 通信 | `application/json;charset=utf-8` | 后端 443，前端 80（后期可调） |
| 部署 | 开发：内网穿透 demo / 生产：云服务器 + Nginx | |

---

## 二、用户量级

- 当前目标：一所学校全体学生
- 后期可能：多所学校 → 全国学校

---

## 三、角色与权限

### 3.1 学生
- 用户名密码登录 / 邮箱验证码登录
- 邮箱验证码注册 / 重置密码 / 修改密码
- 收藏试题集并刷题
- 查看个人答题记录与掌握情况

### 3.2 教师
- 增删改查**自己的**试题集及题目
- 设置试题集信息：名称、描述、备注、开放时间、开放班级
- 按班级控制试题集可见范围
- Excel 导入导出题目
- 查看试题集中每道题的数据统计（谁刷过、错误次数、选项分布等），用图表展示

### 3.3 管理员
- 增删改查**所有**用户、试题集、题目
- 管理学校预设表（schools）和学校人员预设表（preset_students），Excel 模板导入
- 发布系统公告
- 查看操作审计日志

### 3.4 注册规则
- 自主注册的账号默认为**学生**角色
- 注册时提示"如需教师账号请联系管理员"
- 注册流程：填写学号、姓名、邮箱 → 比对 preset_students 表 → 匹配成功发送邮箱验证码 → 验证通过，提取班级信息写入用户表
- 学号+姓名不匹配则拒绝注册

### 3.5 认证方式
- 用户表存 token，SQL 查询判断即验证身份
- 防暴力破解：同 IP 连续失败 5 次锁定 15 分钟
- 邮箱发送使用 QQ 邮箱（开发时预留配置项，后续填入 key）

## 四、班级体系（试题集可见性控制）

### 4.1 schools（学校预设表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| school_name | VARCHAR | 学校名称 |
| created_at | DATETIME | 创建时间 |

- 初期仅本校一条数据，为多校扩展预留

### 4.2 preset_students（学校人员预设表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| student_no | VARCHAR | 学号 |
| name | VARCHAR | 姓名 |
| class_name | VARCHAR | 班级名 |
| school_id | INT | 关联 schools 表 |
| is_registered | TINYINT | 是否已注册（默认 0） |

- 管理员通过 Excel 模板导入（列：学号、姓名、班级、学校）

### 4.3 试题集可见范围

- 教师创建/编辑试题集时勾选"开放班级"
- 通过 `question_set_class` 关联表存储（question_set_id ↔ class_name）
- 学生仅能看到自己班级被授权的 + 标记为"公开"的试题集
- 后期扩展：支持指定到具体学生（user_id 级别）

## 五、题目

### 5.1 题型表（question_types）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| type_code | VARCHAR | `single_choice` / `multi_choice` / `true_false` / `fill_blank` / `essay` / `coding` |
| type_name | VARCHAR | 单选题 / 多选题 / 判断题 / 填空题 / 简答题 / 编程题 |
| has_options | TINYINT | 是否有选项（1=前端展示选项区） |
| option_type | VARCHAR | `single`（单选）/ `multiple`（多选）/ `none`（无选项） |
| answer_format | VARCHAR | `single_key` / `multi_key` / `text_list` / `text` / `code` |

- 新增题型只需插入一行数据，无需 ALTER TABLE
- 前端根据 `option_type` 和 `answer_format` 自动切换渲染组件

### 5.2 试题集

- 教师创建试题集 → 往其中添加题目
- 试题集属性：名称、描述、备注、开放时间、开放班级
- 目前仅「试题集」类型，未来扩展「考试」类型

## 六、Excel 导入导出

### 6.1 模板下载

- 提供两种模板：**基础版**（单选/多选/判断）、**完整版**（全部题型）
- 表头（带批注）：

| 题型 | 题目内容 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 正确答案 | 解析 | 难度 | 知识点标签 |
|------|---------|-------|-------|-------|-------|-------|-------|---------|------|------|-----------|

- 题型列、难度列：下拉限制，防止填错
- 正确答案列：
  - 单选 → `A`
  - 多选 → `A,C,D`
  - 判断 → `对` / `错`
  - 填空 → `答案1|答案2`
  - 简答 → 参考答案文本
- 解析列：纯文本，含图片需在系统内通过富文本编辑器插入

### 6.2 导入

- 逐行校验（题型合法性、答案格式、必填字段）
- 校验通过的行批量入库，失败的行返回错误原因（如"第 3 行：多选答案格式错误"）
- 支持部分成功导入
- 题干完全相同 → 提示教师确认是否跳过

### 6.3 导出

- 格式与导入模板一致
- 包含题目全部信息
- 图片以 URL 形式保留

## 七、答案/解析中的图片处理

1. **上传**：教师通过富文本编辑器（Quill）粘贴/上传图片 → 后端校验（jpg/png/gif/webp，≤5MB）→ 存入 `/uploads/questions/{question_id}/`，UUID 命名 → 返回 URL，前端以 `<img>` 嵌入
2. **访问**：开发环境 SpringBoot 静态映射；生产环境 Nginx 直接代理 `/uploads/`
3. **清理**：删除题目同步删图片；更换图片删旧文件

## 八、刷题模式

### 8.1 试题集

- 学生**收藏**试题集后才能刷题（收藏时自动创建对应的错题集）
- 可按**题型**、**难度**筛选
- 可指定：题目顺序是否打乱、选项顺序是否打乱

### 8.2 普通答题模式

| 题型 | 交互 |
|------|------|
| 单选 / 多选 / 判断 | 点击选项 → **立刻**标出对错、显示解析（多选清晰标出用户所选和正确答案） |
| 填空 | 完成填空 → 点击"核对答案" → 显示解析 |
| 简答 | 完成作答 → 点击"核对答案" → 显示解析 |
| 所有题型 | 可立刻添加到错题集 |

### 8.3 考试答题模式

- 完成所有题目后**统一交卷**，交卷前不可看答案
- 有未答题时提示，可跳转到未答位置或执意交卷
- 交卷后同普通模式展示答案和解析，此时可添加错题
- 交卷后保存答题记录（用时、错题数、每题作答详情）
- **中途退出**：保存进度（已答题目、用时）
- **再次进入**：提示"有未完成的答题"，可直接跳转继续
- 可查看对该试题集的掌握情况统计

### 8.4 首页

- 学生登录后展示：收藏的试题集列表 + 最近刷题记录 + 整体正确率统计

### 8.5 搜索

- 学生可按试题集名称 / 科目 / 教师搜索可刷的试题集

## 九、错题集

### 9.1 表结构（wrong_questions）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| user_id | INT | 学生 ID |
| question_id | INT | 题目 ID |
| question_set_id | INT | 来源试题集 ID |
| created_at | DATETIME | 添加时间 |

### 9.2 查询逻辑（实时查询，不额外建总错题表）

- **查某试题集的错题集**：`WHERE user_id = ? AND question_set_id = ?`
- **查总错题集**：`WHERE user_id = ?`（去掉 question_set_id 条件，自动聚合）
- 天然保证「总错题集 = 所有分错题集之和」，一张表，无需同步

### 9.3 移除

- 分错题集移除 = DELETE 该行
- 总错题集移除 = 同样 DELETE 该行

### 9.4 来源展示

- 总错题集中，通过 `question_set_id` JOIN 查出试题集名称，前端展示"来自：数学题库"

### 9.5 刷错题集

- 支持题目顺序打乱、选项顺序打乱
